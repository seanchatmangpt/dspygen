# DSPyGen Combinatorial Maximalism

Normative profile: `GGEN-STANDARDS-7D-2026-07-30`.

The implementation preserves existing DSPyGen runtime surfaces and adds one bounded rail:

```text
Git exact tree → admitted observation O* → ontology and policy
→ internal/external candidate lattices → pure kernel → plan
→ transactional local materializer or BRCE intent
→ consequence observation → causal receipt → replay → external verifier standing
```

## Gall checkpoints

| Checkpoint | Executable proof |
|---|---|
| G0 | Git-object census with revision/tree/path/workflow/package/entry-point inventories |
| G1 | Total Chesterton-fence and authority classification for every tracked path |
| G2 | RDF authority, SHACL contract, standing vocabulary, typed refusals |
| G3 | Bounded internal dimensions, constraints, candidates, exhaustive coverage |
| G4 | External identity/consent/trust/jurisdiction/consequence lattice and pairwise coverage |
| G5 | Nine immutable pack classes, deterministic Building Block closure, lockfile |
| G6 | IO-free shared kernel, deterministic plans, typed refusals |
| G7 | Immutable payload transaction, durable intent/result receipts, atomic pointer, chaos boundaries |
| G8 | BRCE grant/consent/idempotency/budget/postcondition enforcement |
| G9 | Exact-tree self-observation, second-manufacture identity, clean-tree and detached replay crown |

`ALIVE` requires all five evidence surfaces. External standing remains `UNKNOWN` until an external verifier admits external consequence evidence.

## Commands

```text
python -m dspygen.architecture.cmd_entry observe
python -m dspygen.architecture.cmd_entry fence-verify
python -m dspygen.architecture.cmd_entry ontology-validate
python -m dspygen.architecture.cmd_entry candidates-enumerate --domain internal
python -m dspygen.architecture.cmd_entry candidates-coverage --domain external
python -m dspygen.architecture.cmd_entry plan --domain internal
python -m dspygen.architecture.cmd_entry receipt-verify --receipt <receipt.json>
python -m dspygen.architecture.cmd_entry replay --receipt <receipt.json>
python -m dspygen.architecture.cmd_entry verifier-report
python -m dspygen.architecture.cmd_entry crown
```

Every command emits machine-readable JSON. Planning and candidate enumeration are non-mutating. Local mutation is confined to the transactional materializer. External mutation is impossible without an injected BRCE adapter, exact grant, scoped consent, resource closure, idempotency, postcondition observation, and causal receipt.
